Privacy Policy

Last updated: November 17, 2026

1. Introduction

X Email Tool is a personal utility designed to help a user access their own confirmed email information through the official X API and the authorization process provided by X.

2. Information Access

The application may request access to the authenticated user's profile information and confirmed email address, subject to the permissions granted by the user and X.

3. Data Collection and Storage

The website does not collect or store personal information. The application is intended to display information returned by X to the account owner. It does not intentionally sell or share users' personal information.

4. Authentication

Authentication is handled through X's official authorization system. Users should never share their X password with this website or with third parties.

5. Third-Party Services

Use of the X API is subject to X's own privacy policy and terms. This project is not affiliated with or endorsed by X Corp.

6. Contact

For questions about this policy, contact the application owner through the GitHub repository.
